# 项目决策记录

## D-001 静态原型架构

使用 HTML、CSS 和原生 JavaScript，不引入构建工具。

## D-002 独立原型

本需求单独创建原型目录，不修改车联网卡券融合后台原型和原Axure导出。

## D-003 入口形态

权益不是新增表单区块，而是“选择适用范围”中的第五种类型，沿用复选框加蓝色选择按钮的既有形态。

## D-004 数据归属

权益产品数据来自E3S；卡券中心在建券时关联已选权益编码，不在本原型中扩展权益履约或核销能力。

## D-005 UI与字段基线

UI以卡券中心SIT测试环境的窄图标栏、顶部工具栏、浅蓝页签和紧凑表单为准；卡券字段以原新增/编辑满减券页面为基线，权益能力嵌入完整表单，不删减其他字段。
