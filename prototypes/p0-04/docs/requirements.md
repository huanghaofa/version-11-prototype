# 卡券中心E3S权益编码关联原型需求基线

## 项目目标

在不修改既有原型的前提下，单独演示卡券新增/编辑时关联E3S权益编码的页面与交互。

## 功能范围

1. 页面框架、字号、色彩、页签和紧凑表单参考卡券中心SIT测试环境。
2. 恢复原卡券新增/编辑页完整字段，不以简化表单替代；包含基本信息、领取规则、核销规则和关联设置。
3. 在备件、工时、精品、套餐之后增加“权益”类型，形态为复选框加“选择权益”按钮。
4. 适用范围类型沿用原规则：一次只能选择一种；取消当前类型后才能改选其他类型。
5. 点击“选择权益”打开弹窗，数据来自E3S权益类产品。
6. 弹窗展示权益编码、权益名称、权益内容；内容默认收起，点击后展开。
7. 支持按权益编码、权益名称查询并勾选多项，确认后回显权益名称和权益编码。

## 非本期范围

- 不修改原Axure导出和车联网卡券融合后台原型。
- 不修改SIT测试环境及任何既有静态原型。
- 不模拟真实E3S接口、权益履约或权益核销。
