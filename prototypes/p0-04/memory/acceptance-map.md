# 验收映射

| 编号 | 验收项 | 通过标准 | 验证方式 |
|---|---|---|---|
| E3S-01 | 独立交付 | 新目录存在，旧车联网融合原型无本次权益改动 | 路径与残留扫描 |
| E3S-02 | 原位置新增类型 | 备件、工时、精品、套餐后显示权益复选框和按钮 | DOM与视觉检查 |
| E3S-03 | 单类型规则 | 选择权益后其他类型不可选，取消后恢复 | 浏览器交互 |
| E3S-04 | 弹窗勾选 | 弹窗可按编码/名称查询、多选并确认 | 浏览器交互 |
| E3S-05 | 内容展示 | 权益内容默认收起并可点开 | 浏览器交互 |
| E3S-06 | 回显 | 确认后回显权益名称和编码 | 浏览器交互 |
| E3S-07 | SIT视觉 | 显示窄图标栏、顶部工具栏、浅蓝模块页签、紧凑小字号表单 | 视觉检查 |
| E3S-08 | 完整字段 | 基本信息、领取规则、核销规则、关联设置及原卡券关键字段均存在 | DOM与静态断言 |
