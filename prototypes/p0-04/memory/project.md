# 项目记忆

## 项目定位

- 项目名称：卡券中心E3S权益编码关联原型
- 创建日期：2026-07-22
- 类型：无构建步骤的静态前端原型
- 入口：`index.html`

## 产品目标

在不污染既有原型的前提下，以SIT测试环境UI和完整卡券字段为基线，演示卡券新增/编辑页面如何在原“选择适用范围”中增加权益类型并关联E3S权益编码。

## 目标用户

卡券中心运营人员。

## 核心页面列表

- 新建/编辑满减券。
- 选择权益弹窗。

## 核心用户路径

- 进入卡券编辑页 → 在适用范围选择权益 → 弹窗查询并勾选 → 确认回显。

## 主要数据对象

- E3S权益产品：权益编码、权益名称、权益内容。
- 卡券适用范围类型与已关联权益编码。

## 交付方式

独立静态HTML原型，可直接双击或通过本地HTTP服务访问。

## 已确认假设

- 适用范围类型一次只选一种。
- 权益弹窗允许多选权益产品。
- E3S为权益产品数据来源。
- 不因演示权益能力删减卡券其他字段。

## 未确认 open items 引用

- 见 `memory/open-items.md`。

## 目录结构

- `js/components/` — 可复用的 B 端公共组件（如高级搜索、弹窗、分页器）
- `js/pages/` — 具体的业务页面逻辑（如仪表盘、线索列表）
- `assets/css/global.css` — 全局 B 端设计规范与通用组件样式
- `assets/css/app.css` — 应用基础样式与布局
- `config/nav.json` — 菜单路由配置（唯一路由数据源，由 `js/nav.js` 动态渲染）
- `mock/data.js` — 全站 B 端模拟数据集与状态机
- `SKILL-evolve-b-prototype.md` — B 端原型迭代演进技能，可供 AI Agent 在后续开发中调用
- `tools/` — 开发辅助工具脚本

## 工作原则

- 先理解现有代码和业务逻辑，再修改。
- 非必要不修改现有板块内容。
- 业务、Mock、文档、记忆和标注工具分别维护。
