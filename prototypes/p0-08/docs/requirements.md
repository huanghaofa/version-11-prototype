# 活动中心兑换券与积分奖励需求说明

## 产品目标

活动中心在创建或编辑活动时，可配置卡券奖励、积分奖励或两者组合。卡券奖励可查询并关联卡券中心已发布的兑换券；积分奖励引用已启用积分配置。活动中心不重复维护兑换券商品/履约规则，也不在活动内直接编辑积分数量与业务场景。

## 目标用户

- 活动中心运营人员
- 活动配置审核人员

## 核心流程

1. 运营在 step1 选择活动奖品：卡券、积分或卡券+积分。
2. 进入 step2 奖励配置。
3. 卡券分支：通过“兑换券”类型页签查询、查看并关联兑换券。
4. 积分分支：从已启用积分配置中选择一项，查看积分、场景、版本和发放对象摘要。
5. 组合模式下同时完成卡券与积分配置，再进入下一步。

## 页面范围

- 活动创建/编辑页的关联卡券步骤。
- 选择卡券弹窗。
- 兑换券规则详情弹窗。
- 已关联卡券列表与移除确认。
- 准入表达本轮原型暂不展示、不参与前端交互校验。
- 积分配置选择弹窗与已选积分摘要。

## 已确认规则

1. 兑换券是卡券中心的卡券类型之一，不在活动中心新增独立奖励业务对象。
2. 活动中心只关联卡券中心卡券 ID；兑换券定义仍由卡券中心维护。
3. 弹窗支持按卡券类型筛选，并明确展示“兑换券”标签。
4. 兑换券摘要至少展示兑换模式、候选商品/可兑数量、履约方式和绑定对象。
5. 仅允许关联“已发布且在有效期内”的卡券；草稿、已失效券不可选。
6. 普通券与兑换券可在同一活动中关联。
7. 选中结果在筛选和搜索切换后保留，确认后统一回填。
8. 活动奖品支持“卡券中心-卡券”“积分”“卡券+积分”。
9. 积分配置入口本轮不展示准入表达限制。
10. 活动只引用一项已启用积分配置，积分数量、业务场景和版本只读。
11. 积分发放使用用户默认卡对应 VIN，并在首次请求时锁定。

## 本期不做

- 不在活动中心编辑兑换券商品、N选M或履约规则。
- 不设计真实接口字段、分页协议和错误码。
- 不改变活动中心既有互斥/叠加规则。
- 不展示用户端兑换流程。
- 不在本页面展示积分预算号、积分场景码、成本中心等成本字段。
- 不实现真实积分发放、重试、补偿与对账。
