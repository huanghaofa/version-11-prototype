# 项目记忆

## 项目定位

- 项目名称：活动中心兑换券与积分奖励原型
- 创建日期：2026-07-28
- 类型：无构建步骤的静态前端原型
- 入口：`index.html`

## 产品目标

让活动中心在创建/编辑活动时支持卡券、积分或组合奖励；卡券分支可关联兑换券，积分分支可引用已启用积分配置。

## 目标用户

- 活动中心运营人员
- 活动配置审核人员

## 核心页面列表

- 活动创建/编辑 - step2 关联卡券
- 选择卡券弹窗
- 兑换券规则详情弹窗
- 积分配置选择弹窗

## 核心用户路径

- 选择活动奖品 → 进入奖励配置 → 配置卡券/兑换券 → 选择积分配置 → 校验进入下一步。

## 主要数据对象

- 活动
- 卡券模板
- 兑换券规则摘要
- 活动与卡券关联记录
- 积分配置及版本引用

## 交付方式

独立、无构建步骤的静态 HTML 原型，通过本地 HTTP 服务运行。

## 已确认假设

- 兑换券是卡券中心中的一种卡券类型。
- 活动中心仅引用券 ID，不编辑兑换券的商品与履约规则。
- 已发布且有效的券才允许被活动关联。
- 普通券和兑换券可同时存在于一个活动。
- 准入表达本轮原型暂不展示、不参与前端校验。

## 目录结构

- `js/components/` — 可复用的 B 端公共组件（如高级搜索、弹窗、分页器）
- `js/pages/` — 具体的业务页面逻辑（如仪表盘、线索列表）
- `assets/css/global.css` — 全局 B 端设计规范与通用组件样式
- `assets/css/app.css` — 应用基础样式与布局
- `config/nav.json` — 菜单路由配置（唯一路由数据源，由 `js/nav.js` 动态渲染）
- `mock/data.js` — 全站 B 端模拟数据集与状态机
- `SKILL-evolve-b-prototype.md` — B 端原型迭代演进技能，可供 AI Agent 在后续开发中调用
- `tools/` — 开发辅助工具脚本

## 工作原则

- 先理解现有代码和业务逻辑，再修改。
- 非必要不修改现有板块内容。
- 业务、Mock、文档、记忆和标注工具分别维护。
