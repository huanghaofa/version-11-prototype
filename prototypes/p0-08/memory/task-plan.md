# 任务计划

> 由总控工作流或项目拆分智能体维护。用于描述面向人的实施计划，不替代 `memory/execution-steps.md`。

## 项目目标

- 交付可演示、可验证的活动中心关联兑换券静态原型。

## 阶段计划

1. 已完成：需求归一化、业务边界确认。
2. 已完成：独立项目结构初始化。
3. 进行中：页面、Mock 数据和核心交互。
4. 待完成：单步验证、全局验证、标注与交付。

## 当前优先级

- 活动创建页与奖励类型/准入联动。
- 兑换券筛选、详情、选择回填和移除。
- 积分配置选择、门槛校验与只读摘要。

## 风险与依赖

- 真实接口字段、兑换券参与互斥/叠加的详细规则以及卡券+积分发放关系尚待确认，本原型只展示页面和交互方案。
