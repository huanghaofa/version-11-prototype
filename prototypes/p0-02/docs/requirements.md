# 卡券多明细批量核销原型需求基线

## 项目目标

针对卡券中心业务场景为 `维修保养（新）`、`BIMC（新）` 的卡券，新增特殊券类型“组合折扣券”。只有该券类型允许在备件适用范围内配置多个核销组合。

原型用于评审卡券中心新增/编辑券的配置改造，并在总览及配套时序中说明 E3S 一次核销多个备件的联动改造；不新增独立的 E3S 操作页、优惠试算页或核销记录页。

## 目标用户

- 卡券运营：新建或编辑组合折扣券，选择自由组合或分组组合，配置共用折扣、商品及数量，也可以通过 Excel 批量导入商品。

## 页面范围

1. 改造总览。
2. 新建/编辑卡券。

## 功能范围

### R-001 条件联动

- 卡券分类新增 `组合折扣券`。
- 业务场景为 `维修保养（新）` 或 `BIMC（新）`、卡券分类为 `组合折扣券` 且适用范围为 `备件` 时，显示“核销组合配置”。
- 其他券类型和其他场景保持原单对象规则，不允许多备件配置。

### R-002 组合方式

- 组合折扣券保留两种组合方式：`自由组合`、`分组组合`。
- `分组组合`支持新增和删除多个核销组合；核销时多组任选一。只配置一个分组时，即覆盖原“固定组合”场景，因此不再单列固定组合。
- 分组内可以配置一个或多个备件，组内商品必须同时核销；每个商品配置“最低核销数量”，实际核销数量可以多但不能少。
- `自由组合`配置一个商品池，核销时可从中任选一个或多个商品；每个商品配置“最大核销数量”，实际数量不得超过该值，未选择的商品不要求核销，一次核销后未使用额度作废。
- 同一商品在同一分组或自由组合商品池内不得重复；分组模式允许商品出现在多个不同分组中。
- 不允许配置商品集合完全相同的两个分组。
- 不再使用固定组合、固定组合总数量或整券最大核销数量。

### R-003 共用折扣与优惠范围

- 自由组合与分组组合共用券级折扣比例，不允许按商品或分组单独设置折扣。
- 分组组合的优惠数量等于各商品最低核销数量；超出最低数量的同商品可以一起核销，但超出部分按原价结算。
- 自由组合按实际选中数量优惠，但每项不超过配置的最大核销数量。
- 自由组合不得混入商品池外商品；分组组合不得混入当前命中分组之外的商品。

### R-004 Excel 批量导入商品

- 自由组合和分组组合均支持下载对应 Excel 模板并上传商品。
- 分组组合模板字段为：组合名称、商品编码、最低核销数量；同一次文件可包含多个分组。
- 自由组合模板字段为：商品编码、最大核销数量。
- 上传后先展示校验结果，至少包含文件名、总行数、可导入行、错误行及错误原因。
- 支持“追加到现有配置”和“清空后覆盖”两种导入方式；有错误行时只导入校验通过的数据。
- Excel 导入与手工选择共用相同的商品编码、重复商品、重复分组及数量校验规则。

### R-005 核销相关页面边界

- 不新增或调整卡券中心原“核销列表”。
- 不展示核销了哪些备件，不新增核销主从明细。
- 不新增优惠试算和 E3S 操作演示页面，但必须在总览及配套说明中明确 E3S 提交核销组合、卡券中心校验商品集合与最低数量并返回整体结果。

### R-006 历史兼容

- 历史券默认不开启多明细核销。
- 历史对象数量默认为 1。
- 已发券使用发券时的规则快照。

## 非本期范围

- 分次核销或部分核销状态。
- 剩余数量保留到下次使用。
- 单条核销明细独立撤销。
- 每个组合配置独立折扣。
- 真实接口调用、真实工单落库和结算。
- 移动端页面重设计；本原型按参照原型保持桌面后台最小宽度 1180px。
- 优惠试算、核销端交互和核销记录改造。
