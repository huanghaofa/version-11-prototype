# 任务计划

> 由总控工作流或项目拆分智能体维护。用于描述面向人的实施计划，不替代 `memory/execution-steps.md`。

## 项目目标

- 交付一个可评审、可交互、可验证的组合折扣券多核销组合配置静态原型。

## 阶段计划

1. 需求归一化
2. 项目结构初始化
3. 数据模型与 Mock 数据
4. 导航与页面骨架
5. 核心页面与交互
6. 每步验证与修复
7. 全局验证
8. 标注生成与交付

## 当前优先级（2026-08-14 第二轮）

- P0：组合折扣券保留“自由组合”和“分组组合”两种方式。
- P0：分组组合只配置一组时覆盖固定组合，不恢复独立固定组合选项。
- P0：自由组合按商品配置最大核销数量，支持任选一个或多个商品一次核销。
- P0：两种组合方式均支持 Excel 模板下载、文件上传、校验预览及追加/覆盖导入。
- P1：同步升级总览、交互说明、标注与 E3S 联动口径，不恢复优惠试算与核销明细页面。

## 风险与依赖

- 真实商品主数据与价格来源尚未确认，使用独立 Mock 数据。
- 正式接口字段和多价格工单行优惠匹配顺序仍待确认。
- 正式 Excel 解析、文件限制及异步阈值仍待研发确认；静态原型使用 Mock 校验结果演示交互。
