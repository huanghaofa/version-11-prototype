# 项目记忆

## 项目定位

- 项目名称：卡券多明细批量核销原型
- 创建日期：2026-07-24
- 类型：无构建步骤的静态前端原型
- 入口：`index.html`

## 产品目标

在指定 E3S 卡券原型的 SIT 页面结构和完整字段基础上，展示卡券中心新增“组合折扣券”，保留自由组合并新增分组组合，同时支持 Excel 批量导入商品，以及 E3S 一次核销多个备件的跨系统联动。

## 目标用户

- 卡券运营

## 核心页面列表

- 改造总览
- 新建/编辑卡券

## 核心用户路径

进入新建/编辑券 → 选择组合折扣券 → 设置共用折扣 → 选择自由组合或分组组合 → 手工配置或 Excel 导入商品 → 配置商品数量 → 提交券配置 → E3S 一次提交 → 卡券中心按对应组合方式整体校验并返回结果。

## 主要数据对象

- 券模板
- 组合方式
- 核销组合
- 组合商品配置
- Excel 导入任务与行级校验结果

## 交付方式

独立、无构建步骤的静态 HTML 原型项目，通过本地 HTTP 服务运行。

## 已确认假设

- 不需要分次核销。
- 一张券一次提交多条明细。
- 分组组合商品配置最低核销数量，实际数量可多不可少；组合之间任选一，组合内商品必须同时核销。
- 分组组合只配置一组时覆盖原固定组合场景，不再单列固定组合。
- 自由组合保留，商品配置最大核销数量，可任选一个或多个商品，未使用额度一次核销后作废。
- 所有组合共用券级折扣，超出最低数量部分不优惠。
- 两种组合方式均支持 Excel 批量上传商品，并先展示校验结果；支持追加或覆盖。
- 原核销列表保持不变，本原型不记录核销了哪些备件。
- 优惠试算与独立 E3S 操作页面不在本原型范围内；E3S 多备件核销规则在总览和配套时序中呈现。
- 不单列固定组合，不配置固定组合总数量或整券最大核销数量；自由组合继续保留。
- 指定参照原型只读，不允许在其目录中改动。
- 多备件配置必须放在原“选择适用范围”位置，而不是独立简化表单。

## 目录结构

- `js/components/` — 可复用的 B 端公共组件（如高级搜索、弹窗、分页器）
- `js/pages/` — 具体的业务页面逻辑（如仪表盘、线索列表）
- `assets/css/global.css` — 全局 B 端设计规范与通用组件样式
- `assets/css/app.css` — 应用基础样式与布局
- `config/nav.json` — 项目初始导航留档；当前 SIT 顶部页签与底部工作页签由 `index.html` 和 `js/nav.js` 协同控制
- `mock/data.js` — 全站 B 端模拟数据集与状态机
- `SKILL-evolve-b-prototype.md` — B 端原型迭代演进技能，可供 AI Agent 在后续开发中调用
- `tools/` — 开发辅助工具脚本
