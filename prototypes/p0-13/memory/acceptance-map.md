# 验收映射

| 编号 | 需求 | 可观察验收标准 | 验证 |
|---|---|---|---|
| AC-01 | 独立交付 | 新目录存在，不修改 P0P1 九月版本原型 | 路径与 git/文件检查 |
| AC-02 | SIT 为准 | 每页展示“SIT 现状为准 / Axure 辅助” | DOM 文本检查 |
| AC-03 | 活动中心页面 | 8 个核心页均能从导航打开 | 导航逐页点击 |
| AC-04 | 活动编辑 | 四步骤和页面配置四页签可切换 | 浏览器交互 |
| AC-05 | 互斥关系 | 活动互斥/卡券互斥可切换且边界说明可见 | 浏览器交互 |
| AC-06 | 卡券中心页面 | 13 页全部可从导航打开 | 导航逐页点击 |
| AC-07 | 安全操作 | 保存、发放、导出只显示原型提示 | 点击操作 |
| AC-08 | 标注 | 当前页说明抽屉和蓝色结构化标注可打开 | 浏览器交互 |
| AC-09 | 数据隔离 | 业务记录仅存在于 mock/data.js 且标记为演示 | 文件检查 |
| AC-10 | 交付质量 | 无阻塞 404、JS 语法/运行错误，桌面和移动可接受 | HTTP、console、截图 |
| AC-11 | 下拉枚举 | 活动/卡券常用下拉展示多个已确认选项 | DOM 选项检查 |
| AC-12 | 级联关系 | 主/子场景、品牌/组织、领券窗口/栏目逐级联动，上级切换清空下级 | Chrome 实际点选 |
| AC-13 | 建券场景联动 | 业务场景刷新卡券分类，并切换车型/门店/商城商品 | 新建卡券弹窗交互 |
| AC-14 | 组合活动展示名称 | 创建/编辑均可配置；空值回退原组合活动名称 | DOM、编辑回显、SA 联动 |
| AC-15 | 组合活动适用门店 | 不配置/清空=全部门店；指定门店仅包含可用门店 | 选店弹窗、搜索、分组、清空 |
| AC-16 | 规则边界 | 门店范围不修改子活动与卡券核销范围 | 页面说明、文档关键词 |
| AC-17 | 展示名称列表与表单精简 | 列表新增展示名称列；未配置显示“-”；创建/编辑无“SA 对外展示预览” | DOM、列表数据、弹窗关键词 |
