# SA动态二维码与来源报表后台原型需求

## 1. 原型目标

在保留现有活动中心、卡券中心业务边界的前提下，新增独立“SA活动配置”、SA活动报表和SA卡券报表，用于管理SA可投对象、二维码有效期及来源数据。

原型必须参照当前新零售营销系统SIT界面，复用以下视觉与交互语言：

- 深蓝色左侧导航和NISSAN新零售营销系统品牌区。
- 36px白色顶部工具栏。
- 面包屑、浅蓝色一级页签、白底内容区。
- 紧凑三列/四列查询表单、蓝色查询按钮、白色重置按钮。
- 白底宽表、浅灰表头、蓝色文字操作项、抽屉详情。
- 原型说明通过“标注与说明”统一承载。

## 2. 页面范围

### 2.1 活动中心 > SA活动报表

1. 数据总览。
2. 二维码明细。
3. 活动参与明细。

### 2.2 卡券中心 > SA卡券报表

1. 数据总览。
2. 卡券领取明细。
3. 卡券核销明细。

### 2.3 活动中心原有页面改造

1. 保客活动列表、创建/编辑和详情不再配置或展示“是否允许SA分享”。
2. 原准入配置、领券方式、门店来源、关联卡券/权益和活动互斥能力保持原入口维护。
3. 复制活动只复制活动本身，不自动创建或复制SA投放关系。
4. 活动关闭后，已生成二维码提交时拦截当前活动，二维码内其他有效活动继续执行。

### 2.4 活动中心 > SA活动配置

1. 投放配置列表、新增/编辑、详情：统一配置普通活动或组合活动进入SA可选池。
2. 二维码参数：后台配置SA可选的固定有效时长、“长期有效（至活动有效期）”及默认值。
3. 组合活动读取原组合活动及其子活动快照，用户侧仍按一个“大活动”展示。
4. 适用门店/SA范围由普通活动或组合活动维护；SA活动配置不提供编辑字段、不保存范围副本，仅展示实时继承结果。

## 3. 核心交互

- 左侧菜单可在SA活动报表和SA卡券报表之间切换。
- 两套报表内部均通过页签切换三个视图，并同步URL hash。
- 查询、重置、展开/收起筛选区可操作。
- 数据总览指标卡可下钻到对应明细页。
- 表格支持分页演示、详情查看、导出演示反馈。
- 二维码、活动参与、卡券领取、卡券核销均使用右侧详情抽屉。
- 详情抽屉可从活动参与记录跳转到关联卡券领取记录，也可从卡券记录返回来源活动参与记录。
- 所有涉及手机号、VIN、oneID的数据按照权限口径脱敏展示。
- 复制活动不复制SA活动配置，避免新活动未经检查进入SA可选池。
- 号码级、绑车级、认证级直接读取活动原有准入配置，不配置第二套“SA活动级别”。
- 活动开启后锁定原活动关键字段；SA投放关系在独立页面生效或停用。
- SA活动配置只维护投放对象与状态，门店/SA范围读取活动或组合活动配置。

## 4. 页面内容

### 4.1 SA活动报表—数据总览

- 筛选：统计时间、品牌、区域、来源门店、来源SA、活动、活动参与级别、活动执行方式。
- 指标：生成二维码数、扫码UV、活动参与数、发放卡券数、SA活动转化率。
- 图表：近7日转化趋势、来源SA参与排行。
- 汇总表：来源SA、来源门店、活动、级别、执行方式、扫码UV、活动参与数、发券数、转化率、最后参与时间。

### 4.2 二维码明细

- 筛选：生成时间、sceneId、状态、来源SA、来源门店、活动范围、活动ID。
- 表格：sceneId、SA、门店、活动范围、冻结活动数/版本、生成/失效时间、状态、扫码PV/UV、识别人数、参与数、发券数。
- 详情：二维码基本信息、活动冻结快照、扫码数据、后继/前序场景关系。

### 4.3 活动参与明细

- 筛选：参与时间、活动、来源SA、来源门店、级别、执行方式、手机号、VIN、sceneId、结果。
- 表格：参与流水、活动、级别、执行方式、脱敏手机号、脱敏VIN、参与主体、来源SA/门店、sceneId、参与时间、来源确认时间、结果、发券数。
- 详情：活动快照、准入节点、用户车辆快照、来源信息、执行结果、关联卡券。

### 4.4 SA卡券报表—数据总览

- 筛选：统计时间、品牌、区域、来源门店、来源SA、来源活动、券模板、卡券状态、是否跨店核销。
- 指标：发放卡券数、已激活数、已核销数、卡券核销率、跨店核销数。
- 图表：卡券生命周期转化、来源SA卡券核销排行。
- 汇总表：来源SA/门店、券模板、来源活动、获取方式、发放数、激活数、核销数、失效数、核销率、跨店核销数。

### 4.5 卡券领取明细

- 筛选：领取时间、券实例ID、券模板、来源活动、来源SA/门店、手机号、VIN、归属类型、获取方式、状态；状态使用未激活、已激活、已核销、已过期。
- 表格：券实例、券模板、来源活动、获取方式、脱敏手机号/VIN、归属类型、来源SA/门店、sceneId、领取时间、来源确认时间、状态。
- 详情：券基本信息、活动参与流水、来源快照、归属关系、生命周期。

### 4.6 卡券核销明细

- 筛选：核销时间、核销流水、券实例、来源活动、来源SA/门店、实际核销门店、手机号、VIN、订单号、状态、跨店标识。
- 表格：核销流水、券实例、来源活动、来源SA/门店、归属主体、实际使用用户、实际核销门店、跨店标识、订单号、核销时间、金额、补贴、状态。
- 详情：来源快照、券和活动关联、实际核销用户、核销门店、订单金额、生命周期。

## 5. 数据与权限状态

- 总部账号查看授权品牌全部区域数据。
- 区域账号查看下辖门店数据。
- 门店账号只查看历史来源门店为本门店的数据。
- 实际核销门店不因核销其他门店来源卡券而获得来源SA报表权限。
- 手机号展示为 `138****5678`。
- VIN展示为 `LVH******1234`。
- 后台oneID仅显示部分字符。
- 导出动作仅做原型反馈，不产生真实文件。
- 卡券不存在“已使用”业务状态；核销成功即代表卡券完成使用，报表统一使用“已核销”和“核销率”。

## 7. SA活动配置规则

- 投放对象类型分为普通活动、组合活动；一个配置只关联一个投放对象。
- 选择投放对象复用现有大弹窗范式：可选/已选页签、条件查询、表格选择、确认/取消；不使用简单下拉框。
- 门店/SA范围在普通活动或组合活动中配置；SA活动配置页面只读展示来源与当前继承值，不允许二次编辑。
- 普通活动候选必须已启用、可由用户主动领券/抽奖，后台统一推券和用户行为触发活动不得进入候选池。
- 组合活动作为一个整体投放；配置页可查看其子活动、人群包和奖品快照，但不在此重复维护。
- 准入配置沿用原页面结构：是否启用准入、准入等级（号码级/绑车级/认证级）、校验节点（进入活动/领券前/抽奖前/触发发券前）。
- 活动互斥沿用原活动中心“选择互斥活动”能力，不新增“SA互斥配置”。
- 二维码固定有效时长由后台配置候选集合和默认值，范围为5分钟至1天；另支持“长期有效（至活动有效期）”，SA不能自由输入。
- 长期有效的二维码截止到冻结活动中最晚结束时间；各活动结束或下线后仍按实时状态过滤。
- 参数变更只影响新生成二维码，既有二维码保存生成时的有效期模式、时长、生成/失效时间和配置版本。
- 组合活动参与唯一键为“组合活动ID + VIN”；一次参与可同时执行当前VIN命中的多个子活动。
- 同一VIN命中多个子活动时，全部发放对应卡券和权益；不阻断、不记为异常，不设优先级和执行顺序。
- 组合活动仅保留一条参与主记录，同时保留命中子活动及对应发放明细。
- 组合活动可维护“组合活动展示名称”；SA投放对象、二维码快照和用户端优先使用展示名称，未配置时回退原组合活动名称。
- 原组合活动名称始终保留为后台识别与追溯字段，不改写子活动名称。
- 组合活动适用门店由组合活动配置统一维护；未配置或清空时按全部门店生效，配置时仅可选择可用门店。
- SA可见与分享资格为：独立SA投放有效 ∩ 组合活动启用 ∩ 当前SA所属门店命中组合活动适用门店。
- 组合活动适用门店不修改子活动适用范围，也不修改卡券核销门店范围。

## 8. 非本次原型范围

- 服务助手移动端二维码生成页和“我的SA数据”。
- 用户扫码后的活动聚合页。
- 真实登录、权限服务、导出文件和后端接口。
- 卡券中心新增/编辑页增加SA投放字段。
- 新建独立“SA互斥配置”菜单或第二套“SA活动级别”。
- 对真实SIT页面进行保存、发布、启用或关闭操作。
