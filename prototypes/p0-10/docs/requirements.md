# 商城订单金额达N元行为事件后台原型需求基线

## 项目目标

- 在活动中心现有“商城订单”一级分类下，新增行为事件“用户订单消费金额达N元”。
- 支持运营配置金额门槛 N，供活动规则判断订单是否获得一次抽奖机会。
- 原型只覆盖后台配置，不制作商城下单、抽奖、领奖或核销前端页面。

## 功能范围

### R-001 行为事件字典

- 页面延续 Axure“图19-选择行为触发场景”的表格结构。
- 在“商城订单”一级分类下新增“用户订单消费金额达N元”。
- 行为编码展示“待分配”，不虚构正式编码。
- 新增事件默认勾选并突出展示。

### R-002 金额规则配置

- 金额门槛 N 为必填正数，支持两位小数。
- 默认金额口径为“订单实付金额”。
- 默认触发时点为“支付成功后”。
- 默认触发频次为“每订单一次”。
- 保存时校验 N，保存成功后保留配置状态。

### R-003 后台规则表达

- 页面明确展示：订单实付金额大于等于 N 时，生成 1 次抽奖机会。
- 页面说明上报链路及系统边界，但不绘制任何用户端页面。

## 非本期范围

- 商城登录、下单、支付成功页和自动跳转。
- 抽奖页、奖池概率配置、卡券/实物领奖和核销页面。
- 真实订单、发券、库存、物流或核销接口。
- 正式行为编码与退款追溯规则。
- 修改原始 Axure 导出文件。
