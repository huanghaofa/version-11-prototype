# 项目记忆

## 项目定位

- 项目名称：商城订单金额达N元行为事件后台原型
- 创建日期：2026-07-29
- 类型：无构建步骤的静态后台原型
- 入口：`index.html`

## 产品目标

- 将“用户订单消费金额达N元”补入现有商城订单行为事件，并支持运营配置金额门槛 N。

## 目标用户

- 活动运营：选择行为事件并配置金额判断规则。
- 产品、活动中心和新商城研发：评审事件字段、触发规则与系统边界。

## 核心页面与路径

- 唯一页面：行为事件配置页。
- 路径：商城订单事件列表 → 勾选新增事件 → 配置 N、金额口径、触发时点、频次 → 保存。

## 主要数据对象

- 行为事件。
- 金额门槛规则。

## 已确认范围

- 事件位于“商城订单”一级分类。
- 事件名称为“用户订单消费金额达N元”。
- N 可配置且必须大于 0。
- 行为编码暂不分配。
- 不制作用户端下单、抽奖、领奖或核销页面。
