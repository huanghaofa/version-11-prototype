# 项目记忆

## 项目定位

- 项目名称：SA动态二维码移动端闭环原型
- 创建日期：2026-07-17
- 类型：390 × 844服务助手端 + 客户侧移动H5静态原型
- 入口：`index.html`

## 产品目标

让SA选择可投活动并生成冻结范围的动态二维码，可进一步制作带二维码和本人来源信息的分享海报；让用户扫码后在一个聚合页中查看全部推荐活动，并一次完成当前具备资格的领取和抽奖。

## 目标用户

- 日产/启辰服务助手（SA）。
- 已通过oneID识别的日产/启辰用户。
- 已绑多辆车或存在不同人车认证状态的用户。

## 核心页面与状态

- SA选择活动状态。
- 二维码结果与活动冻结快照状态。
- 二维码有效期选择抽屉。
- 我的SA数据概览、活动列表、活动详情、参与记录详情。
- SA卡券列表、卡券详情与简版生命周期。
- 默认活动聚合状态。
- 组合活动未绑车/已绑车及VIN匹配状态。
- VIN选择状态。
- 活动选择状态。
- 一键参与结果状态。
- 绑车/认证离开提示状态。
- SA无可投活动、二维码已替换/过期和活动下线部分未处理状态。

## 核心用户路径

SA自动识别 → 选择普通/组合活动 → 选择二维码有效期 → 生成动态二维码并冻结范围与时长 → 用户扫码 → 加载默认VIN与所选活动 → 组合活动按VIN匹配并在原卡片展示券 → 可选切换VIN → 一键参与 → 统一反馈。SA本人可从选择活动页进入“我的SA数据”，按概览、活动和卡券查看本人脱敏数据并逐级下钻。

## 主要数据对象

- SA来源快照、sceneId。
- 二维码durationMode、durationMinutes、generatedAt、expiresAt和configVersion。
- 海报文案、当前sceneId、来源SA/门店和二维码有效期。
- 组合活动ID、子活动匹配结果和组合活动ID + VIN参与唯一键。
- oneID、默认VIN、绑定车辆与认证状态。
- 活动、活动级别、执行方式、准入状态、参与状态。
- 卡券领取结果、抽奖结果。
- SA本人扫码/参与/发券/核销指标、脱敏参与记录和卡券生命周期。

## 交付方式

- 独立静态项目，支持直接双击index.html预览并兼容本地HTTP调试。
- 不连接真实业务接口。

## 已确认假设

- 用户一定存在默认VIN。
- 后台统一推券活动不进入SA二维码范围。
- 不演示发券失败。
- 绑车/认证后不回跳。
- 移动报表仅展示当前SA本人数据，不提供导出。
- 重新生成新码后旧码阻断新的扫码；活动提交前下线时仅拦截该活动。
- 二维码固定时长范围5分钟至1天，并支持长期有效至冻结活动中最晚结束时间；由后台配置候选项和默认值，SA不可自由输入。
- 分享海报仅开放标题、副标题和扫码引导语编辑，二维码与来源信息固定。
- 组合活动只展示一张卡片，未绑车时不渲染卡券区域或占位框，绑车后按当前VIN展示匹配券。
