SA动态二维码移动端闭环返回原型

功能说明

覆盖SA选择活动、动态二维码、本人移动报表、客户一键参与及二维码生命周期逆向状态的完整移动端闭环。

SA选择活动

  1. 自动读取当前SA姓名、工号和标准门店，不允许切换来源身份。
  2. 仅展示独立SA投放有效、组合活动启用、当前SA门店命中且非后台统一推券的活动。
  3. 组合活动优先展示“组合活动展示名称”，未配置时回退原组合活动名称。
  4. 按号码级、绑车级、认证级分区，支持全选或逐项选择。
  5. 点击活动正文进入详情，查看基本信息、规则、关联卡券、关联权益与互斥关系；基本信息不展示主办方，动作字段显示“领券方式”。
  6. 底部实时显示选择数量；未选择活动时不可生成。

生成二维码

  1. 生成或重新生成前先打开有效期抽屉，后台默认值预选。
  2. SA可选择5分钟至1天固定时长，或“长期有效（至活动有效期）”；取消不生成。
  3. 长期有效截止到冻结活动中最晚结束时间，各活动仍按自身状态实时过滤。
  4. 每次生成唯一sceneId，并冻结活动ID集合、有效期模式、生成/失效时间和配置版本。
  5. 后台后续修改参数不影响既有二维码；新码生效后旧码不再接受新的扫码。

SA活动分享海报

  1. 二维码生成后可进入海报编辑页。
  2. 可使用系统模板，或上传JPG/PNG自定义海报底图（不超过10MB，建议3:4）。
  3. 两种来源均固定叠加当前二维码、SA姓名/工号、来源门店和二维码有效期。
  4. SA可编辑标题、副标题和扫码引导语，输入后实时预览。
  5. 二维码、sceneId和来源信息不可编辑；最终海报可继续编辑，并模拟保存或分享。

我的SA数据

  1. 从选择活动页右上角进入，采用“概览 / 活动 / 卡券”三页签。
  2. 概览展示本人扫码、参与、发券、核销、转化率、核销率和近7日趋势。
  3. 活动列表可进入活动详情，再下钻脱敏参与记录详情。
  4. 卡券列表可进入卡券详情，查看核销情况和最近生命周期。
  5. 仅展示当前SA本人数据，不提供导出。

视觉与数据安全

  • SA选择、二维码和本人数据页面统一使用蓝色主视觉；用户扫码聚合页继续使用红色主视觉。
  • 手机号码和VIN按规则脱敏。
  • 页面不展示用户统一标识。
  • 参与记录保留来源SA、来源门店、准入校验和关联卡券，便于本人追踪。
  • 移动端统计口径与后台SA活动报表、SA卡券报表一致。

进入页面

  1. 识别oneID和二维码冻结的活动ID范围。
  2. 读取默认VIN；多VIN用户始终加载默认车辆。
  3. 分别执行每个活动配置的准入校验节点。
  4. 展示全部活动并计算默认勾选、已参与、互斥已参与或等级不足状态。
  5. 同一互斥组即使都满足准入，也只默认勾选其中第一项。

准入与参与主体

  • 客户页面不展示号码级、绑车级、认证级分区标题或等级标签，活动使用连续列表呈现。
  • 号码级仍按oneID判断，状态不随VIN变化。
  • 绑车级仍按当前VIN判断，切换VIN后重新计算。
  • 认证级仍按当前oneID与VIN的一对一认证关系判断。
  • 组合活动：始终只展示一张卡片；名称沿用展示名称优先/原名回退；绑车前卡券区域整体不展示，绑车后在原卡片汇总展示当前VIN命中的全部券。
  • 组合活动适用门店只控制SA查看与分享，不改变子活动参与和卡券核销门店。
  • 同一VIN命中多个子活动时全部执行，不设优先级和顺序。
  • 组合活动参与唯一键为组合活动ID + VIN。
  • 已参与活动继续展示，但不可再次选择。

核心交互

动作页面反馈业务规则
SA选择活动普通与组合活动均作为一个可选对象，底部实时显示选择数。不可选活动在后台SA活动配置阶段排除。
生成二维码先选择固定时长或长期有效，再展示二维码、sceneId和冻结快照。默认值预选，取消不生成；长期有效截止到冻结活动最晚结束时间。
制作分享海报选择系统模板或上传自定义底图，并实时修改三段文案。上传限JPG/PNG、10MB；二维码、来源SA/门店及有效期统一叠加且不可改。
保存/分享海报最终海报可保存到相册或调起系统分享。海报绑定当前sceneId，旧码失效后旧海报不能继续新扫码。
重新生成再次打开时长抽屉，确认后展示新sceneId。新码生效即阻断旧码新的扫码。
组合活动未绑车一张大卡片可见，卡券区域不渲染、复选框置灰并提供去绑车。没有VIN时不判断人群包，不展示具体券或待解锁占位框。
组合活动已绑车原卡片内汇总显示当前VIN命中的全部专属卡券。不展示人群标签；多子活动命中时全部执行；组合整体按VIN只参与一次。
切换VIN刷新活动状态、默认勾选和组合活动卡券内容。每次仅执行一个VIN；一定存在默认VIN。
客户选择活动可参与活动默认勾选，用户可取消。已参与、互斥已参与、需绑车、需认证活动不可勾选。
一键参与一次执行全部勾选活动，不逐张卡片确认。各活动独立校验；组合活动按组合活动ID + VIN去重，同时执行全部命中子活动。
领券 / 抽奖统一结果弹层直接反馈领券或中奖结果。不演示发券失败。
绑车/认证提示即将离开活动页。完成后不回跳，用户需重新扫码进入。

来源规则

  • 来源在活动成功执行时确认。
  • 不管此前扫描过多少SA二维码，按最终执行触点记录。
  • 页面对用户展示“服务顾问推荐”，不展示后台归属术语。
  • 后台统一推券活动不允许SA选择，不进入本页。
