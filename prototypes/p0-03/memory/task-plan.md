# 任务计划

> 由总控工作流或项目拆分智能体维护。用于描述面向人的实施计划，不替代 `memory/execution-steps.md`。

## 项目目标

- 交付可评审的 PRD、T+1 流程和双页面静态原型。

## 阶段计划

1. 已确认规则归一化并新建版本目录。
2. 编写 PRD 与飞书兼容流程图。
3. 建立主表、商品/备件明细与规则 Mock。
4. 实现卡券补贴数据查询、分页和明细抽屉。
5. 实现补贴规则查询和增删改查弹窗。
6. 逐步验证、响应式验证、标注与交付。

## 当前优先级

- 当前优先实现业务页面及核心交互，再执行浏览器验收。

## 风险与依赖

- 正式接口技术字段仍待联调，不得在原型中升级为已确认事实。
- 原型数据必须保持虚构和脱敏。
