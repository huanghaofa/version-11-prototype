# 已确认业务规则

## 业务对象定义

- 卡券唯一性：卡券 ID + 完整核销码。
- 补贴主记录：一张卡券一行，一对一关联一个订单或工单。
- 明细快照：当前全部适用商品或备件，不使用来源明细 ID。

## 关键字段含义

- 预计结算金额：退款期内可变化。
- 实际结算金额：超过退款期后由来源系统生成并锁定，生成前为空。
- 补贴规则 ID/名称：核销时关联规则快照。

## 主要状态和枚举

- 核销渠道：线上、线下。
- 数据来源：新商城、E3S。
- 结算状态：未结算、已结算、无需结算。
- 用户字段：VIN，或手机号 + oneID。

## 权限或角色边界

- 来源系统负责金额计算和状态传入；卡券中心只校验、保存、查询、展示。
- 规则继续由卡券中心通过原有页面和接口维护。

## 异常、空状态或边界规则

- 部分退款：预计金额变化，实际金额为空。
- 全额退款：预计金额为 0、实际金额为空、无需结算，记录保留。
- 整单快照校验失败时拒绝全部写入。
