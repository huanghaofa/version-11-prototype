# 项目记忆

## 项目定位

- 项目名称：卡券补贴数据管理原型
- 创建日期：2026-08-19
- 类型：无构建步骤的静态前端原型
- 入口：`index.html`

## 产品目标

展示卡券中心接收并保存来源系统已计算补贴数据后的查询和规则维护能力。

## 目标用户

- 卡券中心运营人员
- 财务/业务核对人员

## 核心页面列表

- 卡券补贴数据
- 补贴规则设置

## 核心用户路径

- 查询卡券补贴记录 → 查看商品/备件明细。
- 查询补贴规则 → 新增/查看/编辑/删除规则。

## 主要数据对象

- 卡券补贴主记录
- 商品/备件明细快照
- 补贴规则

## 交付方式

可直接双击打开的静态原型；HTTP 环境读取 `config/nav.json`，`file://` 环境使用同内容的内置导航兜底。

## 已确认假设

- 卡券中心不计算金额。
- 新商城数据为线上，E3S 数据为线下。
- 一张卡券只关联一个订单或工单。
- Mock 数据为虚构脱敏数据。

## 未确认 open items 引用

- 见 `memory/open-items.md`。

## 目录结构

- `js/components/` — 可复用的 B 端公共组件（如高级搜索、弹窗、分页器）
- `js/pages/` — 具体的业务页面逻辑（如仪表盘、线索列表）
- `assets/css/global.css` — 全局 B 端设计规范与通用组件样式
- `assets/css/app.css` — 应用基础样式与布局
- `config/nav.json` — 菜单路由配置（唯一路由数据源，由 `js/nav.js` 动态渲染）
- `mock/data.js` — 全站 B 端模拟数据集与状态机
- `SKILL-evolve-b-prototype.md` — B 端原型迭代演进技能，可供 AI Agent 在后续开发中调用
- `tools/` — 开发辅助工具脚本

## 工作原则

- 先理解现有代码和业务逻辑，再修改。
- 非必要不修改现有板块内容。
- 业务、Mock、文档、记忆和标注工具分别维护。
