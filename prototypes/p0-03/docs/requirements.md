# 卡券补贴数据管理原型需求基线

## 项目目标

演示卡券中心在不计算补贴金额的前提下，接收新商城/E3S T+1 补贴数据并提供查询、明细查看，同时沿用原有补贴规则页面完成增删改查。

## 页面范围

1. 卡券补贴数据：多条件查询、一券一行、分页、空结果、商品/备件明细抽屉。
2. 补贴规则设置：查询、新增、查看、编辑、删除；同一规则分别配置线上和线下口径，不展示结算渠道字段。

## 已确认数据口径

- 业务唯一键为卡券 ID + 完整核销码，不使用卡券实例 ID。
- 新商城=线上，E3S=线下；订单/工单与卡券为 1:1。
- 用户字段拆为 VIN、手机号、oneID，不展示归属类型。
- 来源系统每次推送当前全部商品/备件明细，卡券中心原子替换当前快照。
- 明细分别保存优惠金额、预计结算金额和实际结算金额。
- 结算状态仅为未结算、已结算、无需结算。

## 非本期范围

- T+1 同步日志前端、E3S 结算批次、账期管理。
- 卡券中心计算或汇总补贴金额。
- 真实接口联调、生产数据和正式权限控制。
