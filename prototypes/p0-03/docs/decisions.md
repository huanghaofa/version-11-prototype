# 项目决策记录

## D-001 静态原型架构

使用 HTML、CSS 和原生 JavaScript，不引入构建工具，除非后续需求明确要求。

## D-002 页面边界

原型只保留“卡券补贴数据”和“补贴规则设置”两页；同步日志只后台保存，不在页面展示。

## D-003 金额责任

优惠金额、预计结算金额、实际结算金额均由新商城或 E3S 传入。原型不提供计算按钮、汇总卡片或手工调整入口。

## D-004 规则页面

复用原有规则管理语义。同一规则包含线上、线下两组配置，不出现结算渠道选择器；Mock 中保留已使用规则的编辑/删除限制提示。

## D-005 展示基线

采用 SIT 后台证据中的深色侧栏、蓝色主操作、白色内容卡、查询区、宽表格和右侧操作列。Mock 仅用于演示，不代表生产数据。
