# 待确认事项

以下问题不阻塞本轮交互原型：

1. 正式业务分类是否沿用历史完整集合，还是收敛为“全部 / 购车 / 商城 / 售后 / 车联 / 其他”。
2. 分类顺序是否按潜客、非网联车主、网联车主动态变化。
3. “售后”是否作为一级分类，还是继续拆成维保、取送车等分类。
4. 正式产品中已使用/已过期是否继续采用本原型的状态筛选，还是拆为独立历史卡券页。
5. 真实车型名称、车辆图片和 VIN 脱敏规则由哪个接口提供。
6. 第三方兑换成功后的状态回调时效、失败重试和人工补偿口径。
7. 正式核销码是否由接口同时返回条形码和二维码内容，以及二维码刷新时效。
8. 通用兑换券撤销、退款恢复和履约失败补偿仍沿用既有任务边界，本原型暂不扩展。
