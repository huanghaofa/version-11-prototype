## 项目目标

验证业务分类筛选与 VIN 共用券分组并存的卡包体验。

## 阶段计划

1. 建立业务分类、车辆、券实例 Mock 数据。
2. 实现移动端卡包框架和业务分类横向筛选。
3. 实现个人卡券和多 VIN 分组。
4. 实现业务分类、状态双维度筛选及空状态。
5. 补齐券种、详情、激活、核销码、兑换码和历史状态。
6. 完成单步验证、全局验证和交互文档。
