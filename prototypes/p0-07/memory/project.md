# 项目记忆

## 项目定位

- 项目名称：卡包 VIN 共用券前端原型
- 创建日期：2026-07-24
- 类型：无构建步骤的静态前端原型
- 入口：`index.html`

## 产品目标

验证卡包业务分类与 VIN 共用券分组的组合信息架构，交付可点击的移动端静态原型。

## 目标用户

- 登录卡包的普通用户。
- 关联一个或多个 VIN 的车主或车辆关联人。

## 核心页面列表

- 卡包首页。
- 券详情底部弹层。
- 核销码底部弹层。
- 分类无结果空状态。

## 核心用户路径

- 进入卡包 → 浏览“全部” → 切换“商城/维保”等业务分类 → 查看手机号券或 VIN 共用券 → 打开详情或核销码。

## 主要数据对象

- 业务分类 `category`。
- 车辆 `vehicle`。
- 券实例 `couponInstance`。
- 券归属维度 `ownerType`：`ACCOUNT` 或 `VIN`。

## 交付方式

独立无构建静态项目，通过本地 HTTP 服务预览。

## 已确认假设

- 顶部“全部/商城”等为业务分类筛选。
- VIN 共用券只保存一个实例，多关联人动态查询同一实例。
- 分类筛选和归属分组是两个正交维度。
- 卡包归卡券中心统一承接。

## 未确认 open items 引用

- 见 `memory/open-items.md`。

## 目录结构

- `js/components/` — 可复用的 B 端公共组件（如高级搜索、弹窗、分页器）
- `js/pages/` — 具体的业务页面逻辑（如仪表盘、线索列表）
- `assets/css/global.css` — 全局 B 端设计规范与通用组件样式
- `assets/css/app.css` — 应用基础样式与布局
- `config/nav.json` — 菜单路由配置（唯一路由数据源，由 `js/nav.js` 动态渲染）
- `mock/data.js` — 全站 B 端模拟数据集与状态机
- `SKILL-evolve-b-prototype.md` — B 端原型迭代演进技能，可供 AI Agent 在后续开发中调用
- `tools/` — 开发辅助工具脚本

## 工作原则

- 先理解现有代码和业务逻辑，再修改。
- 非必要不修改现有板块内容。
- 业务、Mock、文档、记忆和标注工具分别维护。
