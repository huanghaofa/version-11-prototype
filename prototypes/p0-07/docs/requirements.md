# 卡包 VIN 共用券前端原型需求基线

## 项目目标

输出一个可直接评审的移动端卡包原型，验证“业务分类筛选”与“个人卡券 / VIN 共用券分组”同时存在时的信息架构和交互。

## 目标用户

- 登录日产 APP、微信小程序或商城后进入卡包的用户。
- 同一手机号可能关联多个 VIN。
- 同一 VIN 可能关联多个有效手机号，关联人动态查询并看到同一券实例。

## 功能范围

### 页面

- 卡包首页。
- 券详情底部弹层。
- 独立核销码页。
- 通用兑换券四步流程页。
- 无结果空状态。

### 页面结构

1. 顶部页面标题和状态说明入口。
2. 横向业务分类：全部、购车、商城、维保、车联、取送车、试驾、加油、出行、影视、其他。
3. 状态筛选：全部状态、可使用、待激活、已使用、已过期。
4. 分类与状态双重筛选结果说明。
5. 个人卡券分组，仅展示手机号，不展示“与车辆无关”。
6. VIN 共用券分组，按车辆拆分，仅展示当前筛选有数据的车辆；默认车辆使用醒目标识，非默认车辆不展示能源类型标签。
7. 券详情、独立核销码页、第三方兑换码弹层和通用兑换流程。

### 核心交互

- 点击业务分类后原地筛选，不跳转成多套页面。
- 点击状态后原地筛选，并与业务分类组合生效。
- “全部”展示所有业务分类的数据。
- 卡包默认展示可使用券；已使用和已过期通过状态筛选演示。
- 当前分类没有个人卡券时，不展示空的个人卡券分组。
- 当前分类某 VIN 没有券时，不展示该 VIN 分组。
- 点击券卡或“查看详情”打开详情弹层。
- 点击“出示核销码”进入独立核销码页。
- 点击“查看兑换码”打开第三方兑换码弹层，并支持复制。
- 通用兑换券进入独立兑换流程：券详情、选择商品、确认兑换、兑换成功。
- 待激活券可执行激活，成功后转为可使用并切换到后续操作。
- 点击“去使用”展示渠道跳转提示。
- 支持关闭弹层、遮罩关闭和 Escape 关闭。
- 空分类展示空状态，并提供返回“全部”的按钮。

## 核心业务规则

- 业务分类、券种、卡券状态是三个不同维度。业务分类与状态可筛选，券种直接展示在券卡上。
- 个人卡券归当前手机号/oneID；VIN 共用券归具体 VIN。
- 共用券不按关联手机号生成副本。
- VIN 共用券的用户侧提示统一为“车辆有效关联人均可使用”。
- 分类筛选后仍然按归属维度分组，不能把“商城”等分类与 VIN 分组做成互斥层级。
- 同一 VIN 可以存在不同业务分类、不同模板产生的多个券实例。
- 车辆分组标题只展示客户可识别车型名称和脱敏 VIN，不展示年款、配置版本。
- 默认车辆展示醒目的“默认车辆”标识；N7 等非默认车辆不展示“新能源”等能源类型标签。
- 用户侧状态包括 `AVAILABLE`、`PENDING_ACTIVATION`、`USED`、`EXPIRED`；后台“未领取”在前台映射为“待激活”。
- 已使用、已过期券不展示使用操作，只保留详情和记录。
- 线下核销码采用独立页面，展示券摘要、条形码、数字码、二维码和绑定车辆。
- 通用兑换券支持 N 选 M 演示：5种候选商品任选2件，允许同一商品选择2件，也允许跨履约方式组合。
- 通用兑换成功即将券置为已核销；履约、发货、到店核销状态单独展示，不与券状态混用。

## 非本期范围

- 后台建券页和活动配置页。
- 真实 oneID、核销、退款和消息接口。
- 手机号可视关系表、授权转赠和跨手机号券副本。

## 验收方向

- 375px 移动端可完整使用。
- 桌面端居中展示，内容不被拉伸。
- 分类与状态横向滚动、筛选、空状态、详情、激活、独立核销码页、第三方兑换码及通用兑换四步流程均可实际点击验证。
- JavaScript 无语法错误，本地资源无阻塞性 404。
