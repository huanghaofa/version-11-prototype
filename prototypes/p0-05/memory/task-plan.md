# 任务计划

## 项目目标

- 交付一个独立、可维护、可评审的活动中心积分奖励静态原型。
- 覆盖积分配置、认证级活动引用、默认卡 VIN 发放、记录追踪与对账异常闭环。

## 阶段计划

1. 完成项目壳、导航和统一 Mock 数据。
2. 实现积分配置列表、表单、详情和版本记录。
3. 实现活动奖励配置及认证级联动、活动详情快照。
4. 实现奖励发放记录、发放详情、异常补偿和对账。
5. 每个步骤完成后单步验证并记录证据。
6. 全局验证通过后生成页面标注和交互说明。

## 当前优先级

- P0：认证级硬门槛、积分配置独立维护、活动只选配置、配置版本锁定。
- P0：默认卡 VIN、幂等请求、发放结果与异常补偿展示。
- P1：预算配置与预警、对账差异；预算号、额度、使用情况和预警阈值在配置中维护或只读展示，每笔发放固化预算号。
- P2：自动冲正，仅保留扩展位，不实现业务操作。

## 风险与依赖

- 真实 oneID 和积分系统接口字段未确认，原型使用明确标注的 Mock 字段。
- 预算余额以积分系统为权威来源，原型仅模拟查询结果和预警。
- 所有提交、审核、发布、补发、导出均为静态反馈，不产生真实业务数据。
