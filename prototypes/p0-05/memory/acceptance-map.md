# 验收映射

| Requirement ID | Requirement | Acceptance Criteria | Verification | Status |
| --- | --- | --- | --- | --- |
| R-001 | 独立原型可运行 | HTTP 入口返回 200，导航可用，无阻塞错误 | HTTP、DOM、console、资源检查 | Pass |
| R-002 | 积分配置独立维护 | 列表、表单、详情、版本完整；活动内无积分参数输入 | 页面与字段检查 | Pass |
| R-003 | 认证级硬门槛 | 非认证级禁用积分；认证级可选择 | 准入切换交互检查 | Pass |
| R-004 | 活动只选择配置 | 选择后只读展示配置摘要，保存配置 ID 和版本 | DOM 与发布快照检查 | Pass |
| R-005 | 多奖项支持 | 抽奖奖项可分别选择卡券或积分配置 | 奖项新增与类型切换检查 | Pass |
| R-006 | 默认卡 VIN | 发放详情展示锁定 VIN，重试仍使用原 VIN | 详情和补偿记录检查 | Pass |
| R-007 | 卡券同源场景 | 主/子场景枚举和父子级联与卡券中心一致，不出现积分自创场景 | 表单级联、列表、详情与快照检查 | Pass |
| R-008 | 发放异常闭环 | 覆盖成功、处理中、失败、待人工，失败不重抽 | 状态筛选与详情检查 | Pass |
| R-009 | 对账差异 | 可按业务主/子场景、VIN、请求号查看差异和处理状态 | 对账页面检查 | Pass |
| R-011 | 标注能力与文档 | 交互说明可打开；空标注数据不显示标注点；仅一个显隐按钮；无手动新增入口 | 标注运行时与文档检查 | Pass |
| R-012 | 成本中心与积分场景码隐藏 | 所有业务页面均不出现成本中心或积分场景码；业务主/子场景严格沿用卡券中心 | 全路由文本与 DOM 检查 | Pass |
| R-013 | 独立预算配置 | 配置新增/编辑/详情展示预算号、额度、使用情况和预警阈值；活动只读引用；发放与对账固化预算号 | 表单、详情、快照、发放和对账检查 | Pass |

## 规则

- 每个核心需求都绑定可观察验收标准。
- 未确认的正式接口字段不作为原型通过条件。
