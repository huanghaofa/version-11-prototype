# 活动中心积分奖励原型需求基线

## 项目目标

在现有 DFN 活动中心的活动配置链路中新增“积分奖励”能力，形成可评审、可演示的后台静态原型。积分作为活动奖励的一种形式，与卡券并列；积分参数在独立的积分配置中统一维护，活动只选择已生效配置，不重复填写。

## 功能范围

- 积分配置列表、查询、状态筛选、启停与版本查看。
- 新增/编辑积分配置：积分数量、预算号、预算额度、预警阈值、业务主场景、业务子场景、有效期等。
- 业务主场景、业务子场景严格复用卡券中心的两级枚举和父子级联关系，本期按卡券枚举写死，不新增积分专属场景。
- 预算配置独立维护：预算号、预算额度和预警阈值可配置；已用预算、剩余预算和预算使用率只读展示，余额以积分系统查询结果为准。
- 成本中心继续隐藏；不单独配置积分场景码，业务场景严格使用卡券中心业务主/子场景。
- 积分配置审批状态：草稿、待审核、已启用、已停用、已过期。
- 活动新增/编辑页联动：仅当准入表达为“认证级”时允许选择积分奖励。
- 活动内只选择一项已生效积分配置，并只读展示配置摘要。
- 抽奖活动可按奖项分别选择卡券模板或积分配置，一个活动可引用多项积分配置。
- 活动发布时锁定积分配置 ID 和版本，并展示规则快照。
- 积分按用户默认卡对应 VIN 发放；发放、重试、补偿始终使用锁定 VIN。
- 奖励发放记录、积分发放详情、失败补偿和对账异常展示。
- 页面标注、交互说明、业务规则和验证记录。

## 核心页面

1. 原型总览。
2. 积分配置列表。
3. 新增/编辑积分配置。
4. 积分配置详情与版本记录。
5. 活动新增/编辑—奖励配置。
6. 活动详情—积分奖励快照。
7. 奖励发放记录与积分发放详情。
8. 积分对账与异常处理。

## 非本期范围

- 积分扣减、兑换、转赠和积分商城玩法。
- 自动冲正业务规则；仅保留字段和状态扩展位。
- 实际调用 oneID、积分系统或真实活动接口。
- 成本中心配置、财务审批和真实数据导出。
- 修改现有 SIT 或历史 Axure 原型。

## 交付与视觉方向

- 独立目录交付，不污染既有原型。
- 采用 HTML、CSS、原生 JavaScript，无构建步骤。
- 复用 DFN 活动中心既有 B 端布局、颜色、表格、表单和抽屉式交互语言。
- 所有保存、审核、发布、补发、对账动作均为安全静态演示。
