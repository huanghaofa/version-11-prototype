活动中心积分奖励原型功能说明

评审版本：2026-08-14 · 覆盖积分配置、预算配置、卡券同源业务场景、活动引用、发放记录、异常补偿与对账。

一、已确认业务规则

积分适用范围积分作为通用奖品形式，不限定具体活动类型。
准入硬门槛只有准入表达为“认证级”的活动允许选择积分奖励。
发放对象按 VIN 发放；多 VIN 用户使用默认卡对应 VIN。
配置边界积分数量、预算号、预算额度、预警阈值及业务主/子场景均在积分配置中维护。
成本边界成本中心继续隐藏；不单独配置积分场景码。
场景口径主/子场景严格复用卡券中心枚举和父子级联关系，不新增积分专属场景。
活动操作活动只选择已启用积分配置，不在活动内二次配置积分参数。
奖品组合中奖可发卡券或积分；抽奖的不同奖项可分别选择。
版本规则活动发布时锁定配置编码和版本，核心字段调整需创建新版本。
失败原则中奖结果不变，结果查询、重试和补偿均沿用首次锁定 VIN。

三、页面与关键交互

页面用途评审动作关键结果
积分配置列表统一查询和管理配置按状态筛选、查看预算进度展示预算号、额度、使用率、预警状态和卡券同源场景
新增/编辑配置维护积分、预算和业务场景校验预算字段；切换主场景检查子场景级联活动不重复维护这些字段；成本中心不展示
配置详情与版本查看不可变快照查看预算配置、引用活动、创建新版本预算号、额度、已用/剩余及预警阈值可追溯
活动新增/编辑选择奖品准入切换为绑车级，再切回认证级非认证级积分禁用并清空；认证级可选配置
活动详情确认发布快照查看混合奖项和配置版本积分配置编码、版本和业务场景已锁定
奖励发放记录履约追踪筛选失败、打开详情、查询结果锁定 VIN、预算号、请求号、交易号和配置快照可追溯
积分对账与异常发现并处理账实差异打开有差异任务按预算号、业务主/子场景、VIN、请求号定位

四、关键状态

配置草稿 → 待审核 → 已启用 → 已停用/已过期
场景业务主场景 → 对应业务子场景
发放发放中 / 成功 / 失败 / 待人工处理 / 已冲正
对账无差异 / 有差异 / 已处理
本期边界：自动冲正暂不启用，仅保留状态和原交易号；成本中心继续隐藏；预算余额接口、正式字段、场景编码、错误码、查询轮询和对账文件协议需在联调前确认。
