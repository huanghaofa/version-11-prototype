# 任务计划

> 由总控工作流或项目拆分智能体维护。用于描述面向人的实施计划，不替代 `memory/execution-steps.md`。

## 项目目标

- 交付一个可点击、可验证、兼容历史数据的活动中心卡券规则原型。

## 阶段计划

1. 需求归一化
2. 项目结构初始化
3. 数据模型与 Mock 数据
4. 导航与页面骨架
5. 核心页面与交互
6. 每步验证与修复
7. 全局验证
8. 标注生成与交付

## 当前优先级

- P0：保留历史方式、新增“部分叠加互斥”、部分券选择与批量导入。
- P1：冲突校验、保存摘要、关系预览、响应式布局、交互说明。

## 风险与依赖

- 旧接口枚举保持不变；真实落地需新增一种枚举值和两组部分券字段。
- 组合合法性需与商城最终计算规则一致。
- 原型用 Mock 数据演示，不代表当前 SIT 已实现。
