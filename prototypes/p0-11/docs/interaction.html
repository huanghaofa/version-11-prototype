活动中心卡券互斥叠加并行配置

兼容型目标态原型 · 更新于 2026-08-10

兼容原则：旧 Axure 中“无 / 全部叠加 / 指定叠加 / 全部互斥 / 指定互斥”的数据含义保持不变；新增“部分叠加互斥”，两类关系统一落入一张卡券关系表。

改造前后

项目旧方案目标方案
字段结构无 + 四种业务规则方式保留历史方式，新增第 5 种“部分叠加互斥”
同一活动只能表达一种卡券关系选方式 5 后，可同时表达“与 A 叠加、与 B 互斥”
部分券原“指定叠加 / 指定互斥”按单一策略维护历史方式仍维护一种关系；新增方式在同一张表中维护两类行
历史数据按旧枚举值保存无需迁移或重写，继续按原值回显
结果展示活动中心已有卡券互斥列表沿用原列表，关系字段同时展示叠加和互斥

页面与交互

页面 / 操作结果校验
选择规则方式显示 1–5 种业务方式，以及“不配置（无）”方式 1–4 沿用历史含义
选择部分券支持名称/ID搜索、卡券属性筛选、已选页签未发布或已失效不可选；方式 5 中另一清单已选券不可选
批量导入下载模板、上传文件、查看预校验和逐行原因仅通过行写入；已存在跳过，冲突/失效/不存在/重复行不写入
切换为方式 5同一张关系表同时显示叠加、互斥两类行两类都至少 1 张，且同一券不可重复
保存并查看列表保存草稿后跳转“保客活动互斥关系”按当前规则方式校验有效关系
卡券关系表沿用活动中心现有 7 列表格，按每张主券展开目标券关系字段区分“与指定券叠加/互斥”，展示来源活动 ID
活动配置中的关系表增加主卡券 ID、主卡券名称，每条目标关系按全部主券展开新增/导入目标券后自动补齐主券映射；移除按目标关系整体生效
状态列活动配置中的统一关系表隐藏状态列查看关系、批量导入和移除能力不受影响

最终判断顺序

活动互斥 → 卡券互斥 → 卡券叠加 → 均未命中，默认不可组合。
