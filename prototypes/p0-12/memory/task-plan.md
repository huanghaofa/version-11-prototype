# 任务计划

## 项目目标

交付一套可操作、可验证的活动通用适用门店与 SA 门店过滤静态原型。

## 阶段计划

1. 固化需求、页面范围、数据对象和业务边界。
2. 建立导航、活动/门店/SA Mock 数据和共享状态。
3. 实现创建/编辑活动与树形门店选择。
4. 实现 SA 活动池可见、隐藏和分享权限校验。
5. 补齐空状态、风险提示、直接打开回退和响应式布局。
6. 逐步验证、全局验证、生成标注与交付说明。

## 当前优先级

- P0：所有活动共用的可选「适用门店」，空值等于全部门店。
- P0：SA 活动池按所属门店过滤查看与分享。
- P1：编辑态、清空确认、规则校验视图和风险提示。

## 风险与依赖

- 历史数据迁移、发布后生效、既有码处理和真实组织权限均待后续确认。
- 原型不接真实接口，Mock 数据仅用于表达规则。
