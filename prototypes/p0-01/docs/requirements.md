# 通用兑换券需求说明

## 产品目标

在卡券中心新增“兑换券”类型，面向新商城全部商品配置可兑换的 SKU 与数量，并由卡券中心统一承接后台商品选择、用户卡券详情、兑换流程及兑换单履约查询。兑换提交成功即核销券，后续车联网履约、直邮发货和到店核销状态通过履约单独立追踪。

## 现状证据

- SIT 卡券列表真实列结构：卡券、适用范围、核销说明、统计、系统时间、卡券状态、操作。
- SIT 新建页真实分组：基本信息、领取规则、核销规则、关联设置。
- SIT 业务场景真实级联：商城营销 → 新商城。
- SIT 新商城现有券分类：代金券、满减券、折扣券、到店代金券；兑换券为本期新增目标态。
- SIT 代金券分支已有“适用商城商品 / 选择商品 / 上传文件 / 下载模板”入口，商品弹窗包含商品名称查询和目录树，但取证时目录接口持续加载。
- Axure 历史原型包含礼品券、关联商品、卡包、卡券详情和“9位兑换码”页面。旧兑换码流程与本期商品兑换流程无关。

## 已确认范围

1. 通用兑换券支持新商城全部商品，无存量礼品券迁移。
2. 一张券支持多个相同或不同 SKU；后台支持“固定商品组合”和“N选M”两种兑换方式。
3. N选M 示例为“5选2”：运营配置5个候选 SKU，用户兑换时选择2件；可以选择2个不同 SKU，也可以将同一 SKU 数量选为2。
4. 整张兑换券只允许配置一种履约方式，不允许在一张券内混合车联网履约、直邮和到店核销；商品选择范围按整券履约方式过滤。
5. 车型适配在建券、发券阶段控制，兑换时不二次过滤。
6. 兑换券发放时绑定 VIN；前台不提供选车，兑换与履约直接使用券实例绑定 VIN。
7. 用户确认兑换并成功生成兑换单后，卡券中心立即核销券，不等待实际履约、发货或到店核销结果。
8. 本期不支持撤销、退款、恢复券，也不做预占。
9. 日产 App 与微信小程序同时上线，复用同一业务能力。
10. 卡券详情、商品选择和兑换结果页归卡券中心；直邮商品的确认订单与地址选择页归新商城。新商城提供商品、供应商、库存、门店、地址与物流相关信息，车联网提供车辆及车联网履约能力。
11. 履约方式在整券维度使用下拉选择并且只能保存一个枚举值；前台用户只能查看配置结果，不能修改履约方式。
12. 已核销兑换券仍保留在“我的卡券”，用户可点击进入兑换详情，并继续进入“履约/发货状态”页面查询同一兑换单下各商品状态。
13. 商品池覆盖车联网虚拟商品、商城实物和到店服务商品；一期即可从商城全部商品中选择。
14. 商城返回商品库存为 0 时，前台保留商品展示和详情入口，但商品置灰且不可选择；不自动替换候选商品。
15. 后台商品选择弹窗增加“供应商”下拉筛选，供应商数据来源于新商城。
16. 后台新增“兑换券履约”表单页，按兑换单号、履约单号、履约方式、履约状态、供应商等条件查询履约单，并查看逐商品状态与物流/核销信息。
17. 车联网履约逐商品状态为“待履约、履约中、履约成功、失败”；失败时前台弹窗提示联系客服。
18. 直邮商品状态至少包含“待发货、已发货、已签收”，异常失败时提示联系客服；已发货或已签收可进入物流详情查询承运商、物流单号与轨迹。
19. 到店核销商品仅有“待核销、已核销”两种状态。
20. 后台商品选择弹窗支持分页和本页全选；运营翻页或修改查询条件时保留已选结果，提交时汇总全部页的勾选商品。
21. “最多可兑换 SKU 数量”从全局配置改为券与单个商品的关系配置；前台对每个商品分别校验数量上限。
22. 到店核销券的用户流程固定为“展示券实例绑定车辆与 VIN → 选择省 → 选择市 → 选择门店 → 选择商品 → 创建兑换单并核销券 → 展示核销码”；选门店页面的车辆与 VIN 只读展示且不可更改，门店和商品未全部选择完成前不展示核销码。
23. 直邮券选品后，携带商品 ID 与卡券 ID 跳转新商城确认订单页；用户可选择或新增收货地址。商城订单提交成功回跳卡券中心后，才创建兑换单并核销券。
24. 直邮订单提交失败时不创建兑换单、不核销兑换券；原型只模拟该成功顺序，不定义真实签名与回跳协议。
25. 后台适用商品支持文件导入和模板下载：上传弹窗需展示追加/覆盖、Excel要求、字段定义及模拟校验结果；模板字段至少包含SKU编码、商品名称、商品级数量字段和供应商编码。履约方式不放入模板，统一按整券履约方式校验。
26. 后台手工选择适用商品时先展示商品（SPU）列表，再点击“选择规格”下钻选择具体 SKU/规格；候选数量、N选M规则、商品级兑换上限及提交后回显均以 SKU 为最小单位。商品层分页、筛选和本页全选不得丢失已选 SKU。

## 页面范围

- 卡券中心后台：卡券列表、新建/编辑/查看兑换券、商品选择弹窗、兑换券履约列表与履约单详情。
- 前台用户端：卡券中心列表、兑换券详情、N选M商品选择、商品详情、车联网确认兑换、到店省市门店选择与核销码、新商城确认订单模拟、当前兑换详情、已核销卡券兑换详情、兑换单履约/发货状态与物流详情。
- 系统协作：责任矩阵、成功链路、建议接口清单。
