# 项目记忆

## 项目定位

- 项目名称：通用兑换券原型
- 创建日期：2026-07-20
- 类型：无构建步骤的静态前端原型
- 入口：`index.html`

## 产品目标

在卡券中心新增通用兑换券，支持新商城全部商品组合兑换、兑换即核销以及三类履约单查询。

## 目标用户

- 卡券运营人员
- 日产 App / 微信小程序持券用户
- 商城、卡券中心、车联网研发与测试人员

## 核心页面列表

- 原型说明
- 卡券列表
- 新建兑换券与商品选择弹窗
- 用户端查询与兑换流程
- 后台兑换券履约
- 前台履约 / 发货状态
- 系统接口与边界

## 核心用户路径

建券选择整券履约方式并配置同类商品 → 发券（车联网券绑定 VIN）→ 用户按履约类型完成选店/选品/地址 → 创建兑换单 → 卡券立即核销 → 对应履约方异步更新 → 前后台查询状态。

## 主要数据对象

- 兑换券定义与券实例
- 商品 SKU、券-商品关系与单商品最大兑换数量
- VIN
- 兑换单、履约单、逐商品履约状态与物流单

## 交付方式

静态 HTML/CSS/JavaScript，可通过本地 HTTP 服务直接演示。

## 已确认假设

- SIT 是后台页面主基线，Axure 是历史补充。
- 本期同时支持固定商品组合与N选M，默认演示5选2。
- 当前 Mock 包含车联网履约、直邮和到店核销。
- 每张示例券只配置一种履约方式。
- 券实例已绑定 VIN，前台不提供选车或换车。
