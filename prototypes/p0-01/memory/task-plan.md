# 任务计划

## 项目目标

基于卡券中心 SIT 与 Axure 证据，交付通用兑换券后台与用户端可交互原型。

## 阶段计划

1. 已完成：需求归一化与 12 条业务规则确认。
2. 已完成：SIT/Axure/参考任务证据核验。
3. 已完成：独立静态原型项目初始化。
4. 已完成：后台列表、新建兑换券及商品组合配置。
5. 已完成：App/小程序兑换成功主链路。
6. 已完成：系统责任和接口边界。
7. 已完成：脚本、资源及浏览器交互验收。
8. 已完成：增加后台N选M规则及完整前台卡券中心、选品、商品详情与兑换链路。
9. 已完成：扩展全商城商品、供应商筛选和三类履约方式。
10. 已完成：新增后台“兑换券履约”查询表单及履约单详情。
11. 已完成：将前台改为兑换即核销，并增加兑换单履约/发货状态和物流详情。
12. 已完成：后台商品选择弹窗增加本页全选、分页和跨页选择状态保留。
13. 已完成：整券单一履约、商品级最多兑换数量、到店选店与核销码、直邮商城确认订单模拟。
14. 已完成：到店券选门店步骤只读展示券实例绑定车辆、车牌和 VIN。
15. 已完成：适用商品“上传文件”和“下载模板”增加字段说明及模拟校验弹窗。
16. 进行中：商品选择改为商品层分页、SKU/规格下钻选择，并在主表单按SKU回显。
17. 已完成：生成无需本地HTTP服务、可双击打开的单文件静态原型。

## 风险与依赖

- 商品目录 SIT 接口取证时持续加载，未把目录内容伪装成现状。
- 商品下架/库存不足运营策略仍待确认。
- 直邮真实跳转参数、签名、幂等与失败回跳协议待技术联调；原型仅模拟页面和成功顺序。
- 到店门店数据源、核销码真实格式与刷新/失效规则待接口确认；本轮已实现固定演示数据与展示前置条件。
