# 验收映射

| 验收项 | 原型位置 | 验证方式 |
|---|---|---|
| 新商城新增兑换券类型 | 新建兑换券/基本信息 | 检查场景与券分类 |
| 相同 SKU 多件、不同 SKU 组合 | 商品选择弹窗 | 调整数量并选择多个 SKU |
| VIN 自动带入 | App/小程序/券详情与确认页 | 无选车页面；展示券实例绑定车辆与 VIN，选品后直接进入确认页 |
| 兑换即核销 | App/小程序/成功页、接口页 | 确认兑换后立即显示卡券已核销，履约状态独立展示 |
| 页面归属与接口责任 | 系统接口与边界 | 检查职责矩阵 |
| 不做预占/不可逆 | 新建页、确认页、说明页 | 检查提示文案 |
| App 与小程序同流程 | 用户端页面说明 | 检查页面归属描述 |
| 后台支持5选2 | 新建兑换券/兑换规则 | 检查N=5、M=2及重复选择开关 |
| 前台卡券入口完整 | 前台原型/卡券中心 | 从卡券列表进入券详情 |
| 用户完成5选2 | 前台原型/商品选择 | 两个不同SKU或同一SKU数量2均可进入下一步 |
| 商品详情可查看 | 前台原型/商品选择 | 点击商品详情并返回继续选择 |
| 库存为0不可选 | 前台原型/商品选择 | “在线音乐会员月卡”显示已售罄，增加按钮禁用，不能计入已选件数 |
| 已核销卡券可回看 | 前台原型/卡券中心 | 点击已核销卡片进入兑换详情 |
| 兑换内容完整 | 前台原型/已核销卡券详情 | 展示商品、数量、履约方式、车辆、单号、时间和已核销状态 |
| 全商城商品可选 | 新建兑换券/商品选择 | 商品池同时包含车联网商品、商城实物和到店服务 |
| 供应商筛选 | 新建兑换券/商品选择弹窗 | 供应商下拉数据标注来源于新商城，选择后可筛选列表 |
| 后台履约单查询 | 卡券中心后台/兑换券履约 | 按兑换单号、履约方式、状态、供应商筛选并查看详情 |
| 车联网四态 | 前台/履约发货状态 | 展示待履约、履约中、履约成功、失败；失败可弹窗联系客服 |
| 直邮状态与物流 | 前台/履约发货状态 | 展示待发货、已发货、已签收/失败；已发货可打开物流详情 |
| 到店核销两态 | 前台/履约发货状态 | 仅展示待核销、已核销两种状态 |
| 商品选择分页与全选 | 新建兑换券/商品选择弹窗 | 默认每页5条；本页全选/取消生效；翻到第2页后第1页选择仍保留；筛选后回到第1页并更新总数 |
| 整券单一履约 | 新建兑换券/兑换规则 | 履约方式为整券下拉；商品弹窗只显示兼容商品；切换时提示移除不兼容商品 |
| 商品级最多兑换数量 | 新建兑换券/已选商品与商品弹窗 | 每个候选商品单独填写上限；页面没有全局“单SKU最多可兑”输入 |
| 到店先选门店 | 到店兑换券/选择门店 | 必须依次选择省、市、门店；未选完时不能进入选品 |
| 选店页只读VIN | 到店兑换券/选择门店 | 展示券实例绑定车型、车牌和VIN；页面没有选车、换车或可编辑VIN控件；切换省市门店后信息保持不变 |
| 到店核销码前置条件 | 到店兑换券/商品选择与核销码 | 门店和商品完成后创建兑换单，卡券显示已核销、门店状态待核销并展示核销码 |
| 直邮商城确认订单 | 直邮兑换券/商城确认订单 | 展示 couponId、productIds；可选择或新增地址 |
| 直邮成功后才核销 | 商城确认订单/当前兑换详情 | 模拟失败仍提示券可用；提交成功回跳后显示卡券已核销、发货状态待发货 |
| 上传商品文件弹窗 | 新建兑换券/适用商城商品 | 点击“上传文件”展示追加/覆盖、文件格式、SKU/数量/供应商字段及模拟校验结果 |
| 下载商品模板弹窗 | 新建兑换券/适用商城商品 | 点击“下载模板”展示模板版本、当前履约/兑换方式、字段必填规则和Excel示例行 |
| 模板遵守单一履约 | 上传文件与下载模板弹窗 | 模板不包含商品级履约方式，说明导入时按整券履约方式校验，不兼容SKU失败 |
| 商品下钻选择 SKU/规格 | 新建兑换券/商品选择弹窗 | 第一层按商品分页；点击“选择规格”进入SKU列表，可勾选规格并单独配置数量上限 |
| SKU/规格回显 | 新建兑换券/适用商城商品 SKU/规格 | 提交后逐行展示商品名、规格名、SKU编码和该SKU的兑换数量规则 |
| 商品层分页与SKU选择保持 | 新建兑换券/商品选择弹窗 | 翻页、筛选及返回规格弹窗后已选SKU不丢失；本页全选作用于当前页所有商品的全部规格 |
