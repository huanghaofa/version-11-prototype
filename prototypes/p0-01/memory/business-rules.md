# 已确认业务规则

- BR-01：兑换券适用新商城全部商品，券定义关联 SKU 与数量。
- BR-02：同一 SKU 数量可大于 1；一张券可包含多个不同 SKU。
- BR-02A：兑换方式支持固定组合和N选M；N选M中的M按商品件数计算，同一SKU的多件会占用多个名额。
- BR-03：整张兑换券只配置一种履约方式；商品池按该履约方式过滤，不允许跨履约组合。
- BR-04：车型适配在建券和发券阶段控制，兑换时不二次过滤。
- BR-05：兑换券发放到 VIN；前台直接使用券实例绑定 VIN，不提供选车或换车。
- BR-06：兑换单创建成功后卡券中心立即核销券，不等待实际履约结果。
- BR-07：本期不做库存预占，不支持撤销、退款或恢复券。
- BR-08：商品库存为0时前台置灰且不可选择；下架、补库存、替换商品或补偿等后续运营处置仍待确定。
- BR-09：页面归卡券中心，商城提供商品接口，车联网按券实例 VIN 提供只读车辆信息和履约接口。
- BR-10：履约方式在整券维度下拉配置，包含车联网履约、直邮和到店核销；前台用户不可修改。
- BR-11：已核销卡券可从“我的卡券”进入只读兑换详情，内容以成功兑换时的商品、车辆和履约快照为准。
- BR-12：商品池覆盖新商城全部商品；直邮商品展示发货与物流信息，到店商品展示核销状态。
- BR-13：库存为0的候选商品仍可查看详情，但不计入已选件数，数量增加按钮不可用。
- BR-14：车联网逐商品状态为待履约、履约中、履约成功、失败；失败提示联系客服。
- BR-15：直邮状态为待发货、已发货、已签收及异常失败；已发货/已签收可查询物流。
- BR-16：到店核销仅有待核销、已核销两种状态。
- BR-17：后台“兑换券履约”统一查询不同履约方式生成的履约单及逐商品明细。
- BR-18：后台商品查询增加供应商下拉，数据来源为新商城。
- BR-19：后台商品选择弹窗支持分页与本页全选；翻页和筛选不清空已选商品，提交时汇总所有页的选择结果。
- BR-20：N选M的单SKU最多可兑换数量按券-商品关系分别配置，前台逐商品校验。
- BR-21：到店券选门店时必须展示券实例绑定车辆、车牌和 VIN，信息只读且不可更改；随后按省、市、门店选择，再选商品，兑换单创建成功后才展示核销码。
- BR-22：到店兑换成功后卡券为已核销，门店履约初始为待核销，两者不得混用。
- BR-23：直邮券选品后跳新商城确认订单并选择/新增地址；商城提交成功回跳后才创建兑换单和核销券。
- BR-24：商城订单提交失败时不创建兑换单且卡券保持可使用。
- BR-25：批量商品模板按兑换方式生成数量字段；N选M使用“单商品最多可兑换数量”，固定组合使用“固定兑换数量”。模板不包含商品级履约方式，导入时按整券唯一履约方式校验兼容性。
- BR-26：手工选品使用“商品（SPU）→ SKU/规格”两级结构；分页与筛选发生在商品层，勾选、候选数N、数量上限、保存关系和回显均以 SKU 为单位。商品层本页全选等同于选中当前页各商品的全部可选 SKU。
