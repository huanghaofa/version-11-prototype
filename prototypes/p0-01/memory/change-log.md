# 项目变更记录

## 2026-07-20

- 创建项目基础框架。
- 基于 SIT 和 Axure 证据实现后台列表、新建兑换券、商品组合选择。
- 实现用户端详情、选车、确认、成功主链路。
- 补充系统责任矩阵、接口清单和未决项。
- 修复 `file://` 直接打开时导航配置被浏览器拦截的问题，增加内嵌导航配置回退。

## 2026-07-21

- 后台新增固定组合/N选M切换，默认演示5选2。
- 履约方式改为按商品下拉选择，当前枚举仅有车联网履约。
- 新增完整前台卡券中心、券详情、5选2选品、商品详情、确认与成功页面。
- 支持两个不同SKU或同一SKU数量2两种选品方式。
- 将兑换成功后的卡券状态统一从“已使用”调整为“已核销”。
- “我的卡券”新增可点击的已核销卡片及只读兑换详情页。
- 商品池替换为流量包、座舱皮肤、氛围灯、导航语音包和音乐会员等车联网虚拟权益。
- 兑换券改为发放时绑定VIN，移除前台选车页面；选品后直接确认，车辆与VIN只读带入。
- 新增零库存限制：在线音乐会员月卡作为已售罄示例，前台置灰、保留详情但不可选择。

## 2026-07-22

- 核销时点改为兑换单创建成功后立即核销，不再等待实际履约结果。
- 商品池扩展为新商城全部商品示例，新增精品实物和门店服务。
- 履约方式扩展为车联网履约、直邮和到店核销，并允许一张券跨类型组合。
- 商品选择弹窗新增供应商下拉筛选，标注数据来源为新商城。
- 后台新增“兑换券履约”查询表单和履约单详情。
- 前台新增“履约 / 发货状态”页面，按商品展示三套状态枚举。
- 失败商品新增联系客服弹窗，直邮商品新增物流详情。
- 已核销卡券详情改为兑换与履约状态分离，并增加履约查询入口。
- 商品选择弹窗增加“全选本页”和分页操作，默认每页 5 条。
- 已选商品在翻页、供应商/分类筛选后继续保留，提交时统一汇总所有分页选择。

## 2026-07-28

- 将履约方式从商品维度上提到整券维度，一张券只允许车联网履约、直邮、到店核销中的一种。
- 商品选择弹窗按整券履约方式过滤；切换履约方式时提示并移除不兼容商品。
- 删除全局“单SKU最多可兑”，改为每个候选商品分别配置最大兑换数量。
- 前台改为三张独立示例券，分别演示车联网、直邮和到店，不再用一张券组合三类履约。
- 到店券新增省、市、门店三级选择，并在选店和选品完成、兑换单创建成功后展示核销码。
- 直邮券新增跳转新商城确认订单模拟，支持选择或新增地址；商城提交成功回跳后才创建兑换单并核销券。
- 新增当前兑换详情，分别展示卡券已核销与待履约、待发货或待核销状态。
- 到店券选择门店页面新增券实例绑定车型、车牌和 VIN 只读卡片，不提供修改入口。
- 适用商城商品的“上传文件”新增追加/覆盖、Excel约束、字段说明和模拟校验结果弹窗。
- “下载模板”新增模板版本、当前规则、字段必填口径、示例行和模拟下载弹窗。

## 2026-08-10

- 后台商品选择由直接勾选SKU改为“商品（SPU）列表 → 选择规格/SKU”两级下钻。
- 商品层继续支持供应商/分类/关键字筛选、每页5个商品及本页全选；选择状态以SKU维度跨页保留。
- 规格弹窗支持选择一个或多个SKU，并按SKU配置最多可兑换数量或固定兑换数量。
- 主表单候选区新增商品名、规格名和SKU编码回显，候选数N改为候选SKU/规格数。
- 新增单文件构建脚本，将CSS、Mock数据、导航、全部页面脚本及标注运行时内嵌为 `通用兑换券静态原型_20260810.html`，无需启动本地服务。
